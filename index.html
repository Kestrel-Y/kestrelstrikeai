导航栏「DSH 对话」内嵌真实 DeepSeek Harness 桌面客户端——不是仿 UI。 DSH 负责编排与自主执行，平台工具面（MCP / Skills / C2 / 知识库）作为受治理的能力来源； 可与平台主对话并行，适合多目标、多会话同时推进。

多线作战

  • 多会话并行：不同目标、不同项目工作区可同时开打，互不抢同一条时间线
  • 工作区对齐平台项目：面板「工作区」= 平台项目目录，证据与事实回流同一项目黑板
  • 与主对话互补：主对话走作战模式编排；DSH 走桌面级 Agent 循环，可同时在线

MCP · Skills 同台调用

  • 经平台 MCP 通道调用资产 / 漏洞 / C2 / WebShell / 知识检索等，RBAC 按账号令牌判定
  • 可加载平台 Skills playbook，按任务形状选方法论，而不是裸模型硬猜
  • 工具调用进平台监控账本；被拒调用记 blocked，可复盘

渗透测试独立模式

  • 渗透测试模式
  • 权限预设
  • Agent 预设
  • 授权范围自检
  • 渗透测试模式：面向授权范围内的作业——平台工具优先、授权范围自检、结果回流证据链
  • 只读 / 审计类账号看不到该模式；能动手的账号才可选，避免「点一下提权」
  • 权限档位切换写入平台审计（dsh.permission_mode），谁改了模式可追溯

审核 · 审计 · 产品自保护

  • 审批闸门

    DSH 权限预设可要求原生命令先审批；高风险动作不静默放行。

  • 平台审计

    模式变更、产品路径硬拒绝等落平台审计；与主台账同一套复盘入口。

  • Product Guard

    触及平台安装树（源码 / skills / 二进制等）任意档位硬拒绝并记审计。

  • 同源内嵌

    客户端挂在平台同源路径，无第二端口、无跨源 iframe 拦载问题。

AI 大脑同步协同作战MCP 原生工具

AI 在这里不是"看着操作员操作"的旁观者：运维台里能做的事，它通过 MCP 工具同样能做， 并且和人的操作走同一套权限与审计。

  • 看会话、任务、事件、代理、凭据，一眼看清当前态势
  • 派向指定会话下发任务默认仅放行侦察类
  • 等有界等待任务完成并取回输出，不必反复轮询
  • 调调整 beacon 间隔，按需要降噪或提速
  • 同步与运维台读同一条事件流，看到的是同一份状态，不是事后读一份离线报告

它拿到 C2 不是无限制的 工具白名单（默认只放行只读侦察动作）、c2:task 权限点、人工确认三道约束叠加； shell、inject、cred_dump 这类会改变目标状态的动作会被拒绝，须人工在「C2 运维台」确认。

每条任务都要给理由 派发任务时"为什么现在要做这一步"是必填，这句话连同结果一起进审计，可回放复盘。

C2 的安全边界

  • endpoints 白名单：留空时任何持有 c2:connect 的用户都能让后端连任意可达地址，并借错误信息探测端口——等于一个 SSRF 原语。生产部署应显式填写。
  • 证书固定优先：配了 ca_file 就以证书固定为准，insecure_skip_verify 只是实验环境的退路。
  • 专用运维账号：建议用 role=operator 而非 super_admin——链路身份就是"平台能对团队服务器做什么"的上限。
  • 口令不落配置文件：自动连接的口令只从环境变量或 0600 文件读取。配置文件会进版本库、进备份，也会出现在 GET /api/config 的响应里。
  • 可直接关闭：c2.enabled: false 时整个 /api/c2 路由组不注册，控制台页面明确提示未启用，而不是留一个空壳页面。
