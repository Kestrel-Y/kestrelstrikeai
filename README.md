- 预览包：https://github.com/Kestrel-Y/kestrelstrikeai/releases

## 开源边界

本仓库**只公开**：

1. 社区文档站（本 Pages 站点）
2. **预览编译包**（GitHub Releases 附件，无源码）
3. 试用申请渠道（Issues）

**核心源码、签发私钥、C2 内部实现等不开源。** 获得试用资格后，通过申请渠道私下发放部署包与试用证书。
