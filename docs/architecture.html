系统架构与上游基石

KestrelStrikeAI 是以 Web 管理面为入口、以 Agent 与 MCP 工具为执行核心的安全测试编排平台。社区仓不开源核心代码；本节说明能力分层与开源前身关系，便于评估部署与试用。

上游前身与基石（致谢）

本产品衍生自开源项目 CyberStrikeAI（Ed1s0nZ/CyberStrikeAI）（Apache License 2.0）。上游奠定了当前平台的工程与产品骨架，特此致谢：

  • Go + Gin：服务端与 Web API 路由骨架
  • Eino 多代理：单代理 / Deep / Plan-Execute / Supervisor 等编排模式
  • MCP 联邦：内置工具 + YAML 工具 + 外部 MCP 接入
  • 多层作战记忆：会话 / 项目事实 / 证据与审计等可回溯记忆分层（在上游记忆体系上延续演进）
  • AI 围栏 · HITL：高风险动作闸门与人工确认

KestrelStrikeAI 在此基石上完成产品化重命名、授权交付、C2/DSH 等能力扩展与二次开发。上游获得的荣誉与社区入口归属上游项目，不代表本衍生分支。开源合规说明见 开源免责协议。

分层说明

Web 层

Gin 承载控制台、落地页、激活页与 API。静态资源与模板随发行包分发。

Agent 层

Eino ADK 驱动推理与工具调用；多代理由角色 / Skills / 黑板事实协同。自然语言意图经 Reason→Explore→Fact→Reflect 闭环落地为受控动作。

MCP 与工具

内置 Go 工具、YAML 命令配方、Skills 文件系统与外部 MCP 联邦。工具输出结构化写入资产 / 候选发现 / 证据，供攻击链与报告引用。

记忆与证据

作战记忆分层保存会话轨迹、项目事实、证据条目与审计日志，支撑回放与复核——结论须能回溯到原始工具输出。

治理闸门（AI 围栏）

策略拦截、风险分级与 HITL 审批把高危动作关进人工确认；授权版本（试用 / 正式 / 企业）决定功能位边界。
