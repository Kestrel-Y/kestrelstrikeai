部署手册

面向获准试用 / 正式交付后的落地：拿到发行包或预览包之后，如何在不同系统与架构上安装、激活、升级。核心源码不开源；公开仓仅提供文档与编译产物。

0. 先选部署路径

场景推荐路径架构
Kali / 红队本机（要本机渗透工具链）解压二进制 + systemdlinux/amd64（为主）
干净 Linux 服务器（只要 Web 平台）Docker Composelinux/amd64 · linux/arm64
macOS 本地体验 / 预览预览包直接跑二进制darwin/amd64 · darwin/arm64
内网隔离、无外网离线发行包 + 离线激活同 Linux 二进制
私有镜像仓库docker pull + compose pull 模式按仓库标签

容器镜像刻意不含 nmap/sqlmap/nuclei 等工具。要让 Agent 真正调工具，请用 Kali 本机二进制部署，或自行基于 Kali 扩展镜像。

1. 拿到包先自检（30 秒）

tar xzf kestrelstrikeai-preview-*.tar.gz   # 或正式发行包
cd kestrelstrikeai-*/
./kestrelstrike-ai --build-info

核对：版本号、通道（dev/production/release）、是否编入授权公钥。正式交付应为 release 通道。

2. Kali / Linux 本机（二进制）

2.1 依赖

sudo apt-get update && sudo apt-get install -y ca-certificates tzdata curl
# 渗透工具：nmap httpx nuclei sqlmap ffuf … 按需 apt install

2.2 解压与启动

sudo mkdir -p /opt/kestrelstrike
sudo tar xzf kestrelstrike-*-linux-amd64.tar.gz -C /opt/kestrelstrike --strip-components=1
cd /opt/kestrelstrike
cp config.example.yaml config.yaml   # 按需改端口、模型、授权
./kestrelstrike-ai --config config.yaml
# 浏览器打开提示地址；首次到 /activate 激活

2.3 systemd（长期运行）

# 典型 unit：WorkingDirectory=/opt/kestrelstrike
# ExecStart=/opt/kestrelstrike/kestrelstrike-ai --config config.yaml
# 具体 unit 随正式发行包内 docs / install.sh 提供
sudo systemctl enable --now kestrelstrike

amd64 为默认交付；arm64（如部分云主机 / 树莓派类）需对应 linux-arm64 包。

3. Docker / Compose（Linux 服务器）

# 获准后拿到的发行包内通常含 Dockerfile / docker-compose.yml
docker compose up -d --build
# 或拉取私有仓库镜像：
# docker compose -f docker-compose.pull.yml up -d
  • 持久化卷：data/（库、会话、证书）、自定义 skills/roles（如有）
  • 端口：默认参考包内 compose（常见 18080）
  • 生产务必 TLS 或反向代理；改默认管理员密码

4. macOS 预览

tar xzf kestrelstrikeai-preview-darwin-*.tar.gz
cd kestrelstrikeai-preview-darwin-*/
cp config.example.yaml config.yaml
./kestrelstrike-ai

社区公开预览包当前常见为 darwin/amd64（Apple Silicon 可用 Rosetta 或等待 arm64 预览包）。仅用于授权范围内的本地体验，不作为生产交付。

5. 激活（试用版 / 正式版 / 企业版）

  1. 打开产品 /activate
  2. 无激活码：先走社区 申请试用版激活
  3. 有激活码且能出网：在线激活
  4. 内网隔离：导出激活请求 → 厂商签发 → 导入证书

版本说明：试用版与正式版能力相同（不含企业专属 C2 / 外部 MCP / Skills 配置 / 知识库配置）；企业版默认全开。

6. 升级与备份

  • 备份：config.yaml、data/、自定义资源目录
  • 升级：正式客户使用厂商升级包 / 控制台在线更新；预览包请整包替换后保留 data/
