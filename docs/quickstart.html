快速开始（社区预览）

当前公开内容为预览编译包 + 社区文档。核心源码不开源；完整部署与试用证书需通过申请试用审核后发放。

1. 下载预览包

前往 GitHub Releases 下载最新 preview-* 附件（无源码）。

2. 提交试用版激活申请

在首页填写角色与期望版本（默认试用版），或直接打开对应 Issue 模板。企业申请请填写公司全称与对接信息。获准后收到激活码/证书，到产品 /activate 完成激活。

3. 部署（获准后）

获准后你会收到部署包与试用证书指引。典型路径：

  • Kali / 红队本机：解压发行包，直接跑二进制 + systemd
  • 干净 Linux 服务器：发行包内 docker compose up -d

激活前请阅读 安全声明，并确认目标系统已获书面授权。
